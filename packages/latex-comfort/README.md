# LaTeX Comfort

Core quality-of-life improvements for LaTeX writing in VS Code.

This package exports the stable selection-context API used by the optional
**LaTeX Comfort AI** companion and contains the core LaTeX features.

Current features:

- Compile-problem status bar and Quick Pick navigation.
- Project-scoped Papers view backed by the project `.bib` file.
- Add one paper by DOI, arXiv id, title or BibTeX, then insert `\cite{key}`.

See the repository `docs/paper-basics.md` for Paper Basics usage and limits.
